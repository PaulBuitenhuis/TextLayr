Everything you need, nothing you don't

One small app that does one job properly: turn a talking-head video into a captioned short.

Word-synced popups

A few words on screen at a time with the spoken word lit up and the rest dimmed. Two to six words per popup, your call.

Whisper, running locally

Speech-to-text runs on your Mac via whisper.cpp with DTW word timings for tight sync. Nothing is sent to a server.

Review before you burn

Whisper gets names wrong occasionally. Click any line to jump the preview there, edit the text, then export the version you actually want.

All the style knobs

Font, size, colours, outline, text shadow, glow, an active-word pill or underline, box shape and padding. Wrap over one to three lines, or use a fixed-width bar. Pop, slide or fade captions in and out. One inline panel of about twenty visual controls keeps it approachable. Save the look as a profile and switch between built-ins from a dropdown.

Fast, hardware-accelerated export

VideoToolbox encoding with audio copied through untouched. The transcript is cached, so restyling and re-exporting is instant.

Scriptable CLI included

The same pipeline runs headlessly for batch jobs and automation: textlayr video.mp4 --headless.

Install TextLayr

Requires macOS 13 or later on an Apple Silicon Mac. The download is about 8 MB; the first launch fetches ffmpeg and a Whisper model (~190 MB), which takes a couple of minutes on a normal connection.

Recommended

Disk image

Download the disk image, drag the app into Applications, and allow it once in System Settings. macOS will warn you — that is expected for a free, un-notarized app, and it only happens the first time.

  1. Open the disk image

    Double-click the TextLayr disk image in your Downloads folder. A Finder window opens with TextLayr on the left and an Applications shortcut on the right.

  2. Drag TextLayr onto Applications

    Drop it on the Applications folder, then eject the disk image. Do this before opening it: opening straight from the image makes macOS run a temporary read-only copy, which stops TextLayr updating itself later.

  3. Open it and click Done

    Open TextLayr from your Applications folder. macOS refuses it and offers to move it to the Trash — click Done, not Move to Trash (some Macs label it Move to Bin). The app is fine; macOS just can't verify an app that isn't notarized.

  4. Allow it once

    Open  → System Settings → Privacy & Security and scroll to Security. Click Open Anyway next to the message about TextLayr and confirm with your admin password. Then open the app again.

    No button, or you'd rather not? Clear the flag instead — this also fixes “TextLayr is damaged and can't be opened”:

    xattr -dr com.apple.quarantine /Applications/TextLayr.app

    Swap in ~/Applications if that's where you put it.

  5. Finish setup

    On first launch TextLayr asks which transcription model to use. base.en (~148 MB) is fast and the default; small.en (~488 MB) is more accurate. Click Install and let it download ffmpeg and the model — about 190 MB in total, or about 530 MB with small.en.

    When it's done you're at the drop screen. No account, no sign-in, and no uploads from here on.

You only do this once. After the first launch TextLayr updates itself, and those updates never trip Gatekeeper.

No security prompt

Terminal

One command installs the app and skips the warning entirely — files fetched with curl never get the quarantine flag that browsers add. No password, no System Settings detour. Open Terminal (press ⌘Space, type Terminal, press Return), paste this line, and press Return:

curl -fsSL https://paulbuitenhuis.github.io/TextLayr/install.sh | sh

Read the script first — a self-contained POSIX shell script. It checks the release's SHA-256 and installs to /Applications, or ~/Applications when that isn't writable.

Options

Pass options through sh -s --. --cli installs a textlayr command onto your PATH (and prints the line to add if the folder isn't on it), --version <x.y.z> installs a specific release, and --uninstall removes the app plus everything it downloaded.

curl -fsSL https://paulbuitenhuis.github.io/TextLayr/install.sh | sh -s -- --no-open

Why macOS warns you

TextLayr is free and open source, so it isn't signed with a paid Apple Developer ID and can't be notarized. macOS refuses to open any such app that carries the com.apple.quarantine flag — the mark browsers and AirDrop put on downloads. The terminal install avoids the flag completely; the disk image needs the one-time Open Anyway step above. Either way, updates afterwards are handled by the app.

If something goes wrong
“TextLayr is damaged and can’t be opened”
That's the quarantine flag, not a bad download. Run the xattr command in step 4, or install with the terminal instead.
There's no Open Anyway button
It only shows for about an hour after the blocked attempt. Try opening TextLayr once more, then check Privacy & Security → Security again. Or use the xattr command.
The terminal says this installer is for macOS
You're not on macOS, or you're in a Linux container. TextLayr releases are macOS-only.
The terminal says requires an Apple Silicon Mac
TextLayr has no Intel build. Check  → About This Mac; it needs an M-series chip.
The terminal says requires macOS 13 or later
TextLayr supports macOS 13 (Ventura) and newer. The installer refuses older versions rather than installing an app macOS won't launch.
The terminal says checksum mismatch
The download was corrupted in transit; nothing was installed. Run the command again.
The terminal says TextLayr is running
Quit TextLayr (⌘Q) and run the command again.
I installed it before and still get the warning
Run the terminal install again. It replaces the app and clears the flag.

What happens on first launch

TextLayr downloads what it needs once, then works offline forever after.

ffmpeg + ffprobe

For decoding and encoding video. If you already have them on your PATH (Homebrew, say), TextLayr uses those instead of downloading.

A Whisper model

base.en (~148 MB) is the default and is quick. small.en (~488 MB) is slower but more accurate. You can switch later from the Settings window.

  • Everything is stored in ~/Library/Application Support/textlayr/, plus a small transcript cache in ~/Library/Caches/textlayr/.
  • After setup, video never leaves your machine. No uploads, no accounts.
  • The one other network call is an optional once-a-day check for a new TextLayr release, switchable off in Settings → Updates.
  • English speech is supported today (the models are the English-optimised ones).

Comfortable in a terminal? The app bundle doesn't add textlayr to your PATH by default — re-run the installer with --cli, or use /Applications/TextLayr.app/Contents/MacOS/TextLayr --setup. … --headless video.mp4 runs the whole pipeline without a window. Full flag list in the README.

Questions

Is TextLayr really free?

Yes. It's MIT-licensed open source — no trial, no watermark, no per-minute limits, no account.

Which Macs does it run on?

macOS 13 (Ventura) or later on an Apple Silicon Mac (M-series). There is no Intel build. The source also builds and runs on Linux for development, but releases target macOS.

Do my videos get uploaded anywhere?

No. Transcription runs locally with whisper.cpp, and the export happens on your machine. The only network activity is the one-time dependency download and the optional daily update check.

Do I have to use Terminal?

No — the disk image is the normal route. It needs a one-time macOS security step (click Done, then Open Anyway in Privacy & Security). The terminal command skips that step entirely. Both are on the install instructions.

Why does macOS block it the first time?

Because it isn't notarized (that needs a paid Apple Developer account), and macOS blocks any unnotarized app that was downloaded by a browser or AirDrop. Install from the terminal instead and it never comes up — files fetched with curl aren't quarantined. If you used the disk image, the install steps have the one-time Open Anyway fix. Either way it's a one-time step; updates afterwards are handled by the app itself.

How do I uninstall it?

Quit TextLayr and drag it to the Trash. Then remove what it downloaded — about 250 MB, or ~600 MB with small.en — from Settings → Diagnostics → Remove downloaded models and ffmpeg (this keeps your style preferences), or delete ~/Library/Application Support/textlayr in Finder (this also resets preferences). Or run the terminal installer with --uninstall (this also removes preferences). Videos you exported are never touched.

Do I need to install ffmpeg myself?

No. TextLayr offers to download it on first run. If you already have it via Homebrew it will happily use that.

How accurate is the transcription?

Good enough to be worth reviewing rather than fixing by hand. The default base.en model is fast; small.en is noticeably more accurate on names and jargon. Either way the transcript is editable before export.

Can I use the output commercially?

Yes. The app is MIT-licensed and the video you export is entirely yours.

Can I automate it?

Yes — textlayr video.mp4 --headless runs the full pipeline without the GUI, and there are flags for model, font, colours, position and encoder.

How can I support TextLayr?

TextLayr is free and always will be. If it's useful to you, you can buy me a coffee on Ko-fi — entirely optional. Starring or sharing the project helps just as much.
